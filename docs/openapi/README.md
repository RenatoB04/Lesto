# OpenAPI documentation

The authoritative OpenAPI documents are generated by the running services:

- Identity Service: `http://localhost:5001/swagger/v1/swagger.json`;
- Order Service: `http://localhost:5002/swagger/v1/swagger.json`;
- Payment Service: `http://localhost:5004/swagger/v1/swagger.json`.

The API Gateway routes client traffic, but it does not generate a separate
OpenAPI document. The Gateway base URL for normal requests is
`http://localhost:5000`.

The JSON files in this folder are exported snapshots. Regenerate them after
changing controllers or DTOs so that they continue to match the runtime
contracts. The Payment Service snapshot should be exported separately from
its Swagger endpoint.
